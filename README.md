# 대학생으로 일주일 살아남기

월요일부터 일요일까지 하루 한 번의 선택으로 **학업·체력·행복**을 관리하는 웹 게임입니다.

## 공개 게임

[게임 플레이하기](https://yejoon-y02.github.io/campus-week/)

PC와 휴대폰의 웹 브라우저에서 바로 플레이할 수 있습니다. 로그인이나 설치는 필요하지 않습니다.

## 로컬 실행 방법

1. 이 저장소의 **Code → Download ZIP**을 눌러 다운로드한 뒤 압축을 풉니다. 이미 프로젝트 폴더가 있다면 이 단계는 건너뜁니다.
2. 폴더 안의 `index.html`을 더블클릭해 웹 브라우저로 엽니다.
3. `시작` 버튼을 눌러 플레이합니다.

HTML·CSS·JavaScript가 `index.html` 한 파일에 들어 있습니다. 로컬 실행에는 인터넷 연결, 서버, 패키지 설치, 빌드 작업이 필요하지 않습니다. 브라우저에서 JavaScript가 허용되어 있어야 합니다.

## 게임 규칙

- **기간:** 월요일부터 일요일까지 총 7일입니다.
- **능력치:** 학업·체력·행복은 각각 **50**에서 시작하며, 항상 **0~100** 범위로 제한됩니다.
- **선택:** 매일 두 선택지 중 하나를 고릅니다. 선택 전에 각 능력치의 변화량을 확인할 수 있습니다.
- **결과:** 선택 효과는 한 번만 반영됩니다. 생존한 월요일~토요일에는 결과를 확인하고 `다음 날`을 눌러 진행합니다. 재선택은 할 수 없습니다.
- **종료:** 하나라도 0이 되거나 일요일 선택을 마치면 즉시 엔딩으로 넘어갑니다. 엔딩에서 마지막 선택의 변화량과 최종 능력치를 확인할 수 있습니다.

### 세 가지 엔딩

| 엔딩 | 조건 |
|---|---|
| 재충전 필요 | 능력치 중 하나라도 0이 되면 즉시 종료합니다. 일요일에도 이 조건이 최우선입니다. |
| 균형 달인 | 7일을 생존하고 세 능력치가 모두 40 이상입니다. |
| 아슬아슬 생존 | 7일을 생존했지만 능력치 중 하나 이상이 40 미만입니다. |

### 다시 시작과 진행 상태

엔딩의 `다시 시작`을 누르면 시작 화면으로 돌아가고 능력치가 모두 50으로 초기화됩니다.

진행 상태는 저장하지 않습니다. 새로고침하거나 파일·페이지를 다시 열어도 처음부터 시작합니다.

## 화면과 조작

- 버튼을 클릭하거나 터치해 조작합니다. 키보드에서는 Tab으로 버튼을 선택하고 Enter 또는 Space로 실행할 수 있습니다.
- 폭 390px의 휴대폰 화면에서도 읽을 수 있도록 선택지를 세로로 배치했습니다.
- 능력치는 이름·숫자·막대로, 변화량은 부호와 색상으로 표시합니다.

이 게임은 외부 라이브러리·폰트·이미지 없이 동작하며, 게임 자체의 서버나 로그인 기능을 사용하지 않습니다. 공개 버전은 GitHub Pages에서 제공합니다.
